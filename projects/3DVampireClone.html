3D Vampire Survivor Clone

Low-Level Architecture: Data-Oriented Design (SoA)

About the Project

A deep dive into Data-Oriented Design and Structure of Arrays to develop a custom Entity Component System using C++ in Unreal Engine, to render a 10000 entity swarm without separate actors maintaining 80fps.

Engine Architecture Highlights

  • Data-Oriented Design (SoA): Bypassed standard Unreal `AActor` overhead by developing a custom Swarm Manager. Entities exist as math within flat C++ arrays (Struct of Arrays), maximizing CPU L1 Cache Locality and enabling SIMD auto-vectorization for hot-loop movement.
  • Batch Instanced Rendering: Decoupled the physics math from the graphics pipeline. The CPU crunches the array math and pushes the transform cache to an Instanced Static Mesh component, rendering 10,000+ entities in a single GPU draw call.
  • Event-Driven Subsystem Architecture: Removed UI `Tick` overhead by developing a custom C++ `UWorldSubsystem`. Health and EXP bars update via multicast delegates when certain events broadcast a hit or level-up payload.
  • O(1) Contiguous Array Deletion: Prevented O(N) memory-shifting frame drops by implementing a "Swap and Pop" deletion algorithm. Dead entities are instantly overwritten by the last active element, maintaining a perfectly dense array for branchless iteration.

Tech Stack

  • Language: C++ & Blueprints
  • Engine: Unreal Engine 5.8
  • Deployment: Windows (PC)
  • Features: Data-Oriented Swarm Architecture, Batched ISM Rendering & Event-Driven UI
